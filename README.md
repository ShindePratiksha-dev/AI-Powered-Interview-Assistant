# 🧠 AI-Powered Interview Assistant

A React-based app that simulates an AI interview for full-stack candidates. It features a chatbot for candidates and a dashboard for interviewers.

## 🚀 Features

- Resume upload (PDF/DOCX)
- Chat-based timed interview
- AI-generated questions (Easy → Medium → Hard)
- Interviewer dashboard with scores and summaries
- Local persistence with resume and chat history
- Welcome Back modal for unfinished sessions

## 🛠️ Tech Stack

- React + Redux + redux-persist
- Ant Design (UI)
- OpenAI API (for questions and scoring)
- Vercel (deployment)
